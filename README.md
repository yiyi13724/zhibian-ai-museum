# 智变 · 未来生产力展馆

一座关于人工智能与新质生产力的沉浸式互动展馆。作品将原创三维产业之城、可追溯的研究证据、产业关系图、离散事件协作实验与个人探索档案连接起来，解释 AI 怎样参与技术创新、生产要素重组与价值创造。

版本：2.0。数据核验日期：2026 年 10 月 7 日。数据为固定研究快照，报告版次、观测年份、研究指标及预测情景分别保留。

## 本地打开

1. 完整解压源码压缩包，保留 `assets/`、`modules/`、`vendor/` 与页面文件的相对位置。
2. 双击 `index.html`。Windows 也可双击 `启动网站.cmd`。
3. 使用启用了 JavaScript 的现代浏览器，例如 Chrome 或 Edge。

网站无需安装 Node.js、Python 或构建工具。图表库、三维库、地图和数据均随源码提供，本地浏览无需联网；打开“原始来源”外部链接时需要网络。页面不调用在线 AI 服务，不需要 API 密钥，也不会上传参观档案。

WebGL 可用时显示三维城市；初始化失败时自动显示五个可点击的 SVG 产业展馆。页面其余内容仍可继续使用。

## 六个展区与探索档案

| 展区 | 可以做什么 | 要表达的意义 |
| --- | --- | --- |
| 序厅 | 探索五座原创建筑与中央 AI 数据塔；旋转视角、点选产业、暂停动态、简化画面、重置视角 | 智能能力连接实体生产与知识生产 |
| 时代跃迁 | 在五组证据中切换视角，阅读图表与统计口径，保存证据，导出 PNG 或 CSV | 从采用、投入、成本和具体任务证据理解变化 |
| 产业之城 | 切换五个产业，拖动和点选能力关系图，显示或移除 AI 路径，最多并列对照三种产业并导出 CSV | 数据、AI 能力与人的行动共同形成价值 |
| 协作实验 | 配置合成任务与资源，播放、暂停、单步推进、完成运行；保存两组方案，查看负载与敏感性分析 | 效率、质量、复核和资源约束需要一起评价 |
| 文明边界 | 分辨数据中心历史估计与未来预测，调节资源需求教学假设，记录验证、人工监督或数据治理判断 | 新能力需要资源与责任的共同支撑 |
| 认知挑战 | 将六件展品归为事实、预测或示意，阅读解释并重新挑战 | 学会辨认证据的适用范围 |

探索档案把研究证据、产业路径、实验方案、教学假设与治理判断汇集起来。每条记录可打开详情，查看摘要、解释边界、原始链接，并展开保存的数据或实验参数 JSON；也可填写个人思考，查看六个参观印记，删除单条记录或清空档案，导出可离线阅读、打印的 HTML 参观报告，以及 JSON 备份并重新导入。

## 证据展品的具体视角

- 智能扩散：2023—2025 年 AI 与生成式 AI 双折线、年份游标与播放、100 个比例符号、地区热力图、2025—2026 年规模化差异。
- 全球投入：2025 年 15 个市场的私人 AI 投资榜单、可探索世界分布、2020—2025 年私人投资与企业投资总量趋势及区间缩放。
- 门槛降低：两个历史价格端点的对数图与固定预算换算。
- 劳动协作：客服、写作时间、写作质量、企业软件开发、资深开源开发五张研究指标卡，在各自基准内展示结果；写作两张卡来自同一研究。
- 实体产业：2024 年五大市场工业机器人新增安装量与机构公布的中国全球份额。

每个当前展品都提供数据表、单位、口径、限制与原始链接。CSV 附带数据口径和来源。`data.js` 另保留融资事件与 2026 年价值感受两组补充数据，目前未设置独立展品。

## 操作提示

- 三维城市：拖动旋转；按住 Ctrl 再滚动鼠标滚轮缩放；普通滚轮继续滚动网页。点击建筑或产业入口查看速览。
- 键盘：Tab 在控件间移动；展品与产业标签支持方向键、Home、End；城市画布聚焦后用左右方向键选择产业、Home 重置、Escape 取消选择；详情弹窗可用 Escape 关闭。
- 系统“减少动态”偏好会关闭城市默认旋转，并减少图表动画。城市离开视口或页面隐藏时暂停渲染，渲染上限约 30 帧/秒。
- “策展人导览”按六个节点提供参观提示；全屏按钮、右侧参观导航、页面阅读进度与移动端菜单帮助体验。

浏览器本地存储可用时，档案自动保存在当前浏览器，最多保留 50 条记录。更换浏览器、清除浏览数据或更换访问地址可能看不到原档案；建议导出 JSON 备份。本地存储不可用时，本次页面中仍可探索与导出，关闭页面前应保存备份。

项目使用原生 HTML、CSS、JavaScript，入口通过本地经典脚本按顺序加载模块。交付文件已经可直接浏览，无需重新打包第三方库。修改真实数据时，应同步 `data.js` 的来源、年份、口径及本说明中的对应记录。

## 研究与模型边界

主证据采用 Stanford AI Index 2026 及原始研究；其中多数经济统计观察的是 2025 年，而非 2026 年实时值。生成式 AI 的 2025 年采用率按报告 PDF 正文与图 4.3.1 使用 79%；官网经济摘要中的 70% 与正文不一致，核验说明见 `数据与方法.md`。

不同研究的耗时、产出与质量指标分别展示，不平均为综合“AI 生产率”。工业机器人安装量不是 AI 机器人数量。能源区保留 IEA 2025 报告的 2024 年估计与 2030 年基准预测；第三根教学假设柱不是机构新预测。

协作实验采用固定种子、合成任务与未拟合的教学系数。虚拟分钟、队列轨迹、最终合格率及效率变化都来自本站模型，不能作为真实企业成效或岗位变化的预测。
